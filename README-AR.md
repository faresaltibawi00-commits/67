# تشغيل متجر بنيان الرسمي (بدون تسجيل دخول في كلاود)

المتجر ملفان: `index.html` (الموقع) و`worker.js` (السيرفر على Cloudflare، مجاني). السيرفر يحفظ الطلبات والرسائل، واسمك ورقمك السريين يتخزنون عنده كأسرار ولا يظهرون في الموقع.

## 1) السيرفر
1. ثبّت Node.js ثم نفّذ: `npm i -g wrangler` ثم `wrangler login`
2. أنشئ مخزن البيانات: `wrangler kv namespace create STORE` وانسخ الـ id الذي يطلع وضعه في `wrangler.toml` مكان `PUT_KV_ID_HERE`
3. ضع الأسرار (كل أمر يطلب القيمة):
   - `wrangler secret put OWNER_NAME`  ← اسم دخولك
   - `wrangler secret put OWNER_PASS`  ← الرقم
   - `wrangler secret put SECRET`  ← أي نص عشوائي طويل
4. (اختياري، يوصلك الطلب على جوالك حتى لو الموقع مسكّر) أنشئ بوت من @BotFather في تلغرام، ثم: `wrangler secret put TG_TOKEN` (توكن البوت) و`wrangler secret put TG_CHAT` (رقم محادثتك معه)
5. `wrangler deploy` ← يعطيك رابط مثل `https://bunyan-api.xxx.workers.dev`

## 2) الموقع
1. افتح `index.html` وغيّر السطر `const API="https://YOUR-WORKER.workers.dev"` إلى رابط السيرفر.
2. ارفع مجلد الموقع على Cloudflare Pages أو Netlify (Drag & Drop) وتاخذ رابطاً عاماً، وتقدر تربط دومين.

## كيف يشتغل
- أي زائر يسجّل باسمه ورقمه ويتصفح ويطلب بدون حساب كلاود.
- تدخل أنت بنفس الشاشة باسمك ورقمك السريين فتفتح لك «لوحة المالك»: الطلبات + إرسال رسالة للكل أو لرقم محدد.
- الأسعار تُحسب في السيرفر، فما يقدر أحد يعدّلها من المتصفح.

## حدود لازم تعرفها
- العميل يستلم رسائلك وهو فاتح الموقع (تتحدث كل 6 ثواني). التنبيه وهو مسكّر الموقع يحتاج Web Push ونضيفه لاحقاً.
- الدفع الإلكتروني غير مربوط. عند ربطه، المفتاح السري يُوضع كسر في السيرفر ولا يوضع في index.html.
- الرسائل لرقم محدد تُقرأ بمعرفة الرقم. للخصوصية الأعلى نضيف رمز تحقق للعميل.
